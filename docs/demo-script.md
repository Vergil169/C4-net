# 演示脚本

## 场景

业务方提出跨域低时延视频会议保障需求。系统通过多智能体协同完成意图解析、策略生成、仿真下发、遥测验证，并在链路拥塞后自动自愈。

## 讲解顺序

1. 打开 GUI 控制台，展示智能体注册表和跨域拓扑。
2. 输入推荐意图：

   ```text
   请保障北京园区到上海云服务的视频会议业务，要求时延低于50ms，丢包率低于1%，优先避开拥塞链路。
   ```

3. 点击“提交意图”，讲解结构化意图 JSON、任务流和 A2A 消息。
4. 展示生成的 QoS、ACL、路由策略和 dry-run 配置片段。
5. 展示验证结果：SLA 达成。
6. 点击“模拟拥塞”，使天津到济南链路进入 congested 状态。
7. 点击“触发闭环自愈”，展示 Healing Agent 触发重规划。
8. 讲解系统切换到天津到广州到上海的备用路径，并重新完成 SLA 验证。

## 评分点对应

- 前瞻性与融合度：大模型智能体、网络自治、闭环自愈。
- 技术创新性与可行性：多智能体编排、A2A 消息流、MCP 工具目录、跨域策略生成。
- 系统可用性：Web GUI 展示意图、拓扑、策略、遥测和验证结果。
- 交付物：源码、README、测试、演示脚本。
